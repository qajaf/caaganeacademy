# Fluent Hub

📝 Shuruudaha Website-ka Barashada Luuqadaha (Englishka)
A. Qeybta Guud ee Design-ka iyo Muuqaalka
Design-ka: Website-ku waa inuu noqdaa mid qurux badan, casri ah, oo leh Animation iyo muuqaallo soo jiidasho leh (attractive animations and visual elements).

Awoodda: Website-ku waa inuu noqdaa mid awood badan oo si fudud u maareeya xogta badan iyo culeyska isticmaalayaasha badan.

B. Maareynta Casharada (Admin Dashboard)
Adminka (Maamulaha) waa inuu awood u yeeshaa inuu sameeyo waxyaabahan:

Abuurista Casharo Cusub: Inuu soo galiyo casharo cusub (Create New Lessons).

Casharadu waa inay ku jiraan Playlist (tusaale: Level 1, Level 2).

Adminka wuxuu soo galin karaa Video files iyo Files kale sida PDF, ama wax kasta oo waxbarasho ah.

Wax ka Badalka Casharada: Inuu sameeyo Edit casharada horay u jiray.

Ka Saarista Casharada: Inuu Delete ama ka saaro casharada aan loo baahnayn.

Kaydka (Notes/Resources): Inuu u sameeyo meel ay casharadu ku jiraan qoraal sharaxaad ah (Note) oo la xiriira casharkaas, iyo meel Download lagu sameyn karo files-ka (PDFs, iwm).
